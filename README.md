# Brisbane & Gold Coast dinner shortlist

A Japanese, mobile-friendly comparison page for 13 dinner candidates in Brisbane and the Gold Coast.

- `index.html` — page layout, styles, filters, and sharing button
- `data.js` — venue details, official reference links, and 12 linked photo sources per venue

## Preview locally

Open `index.html` in a browser. The page is static and does not need a build step.

## GitHub Pages

To publish from this repository, enable Pages under **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The expected project URL is `https://ryuuto200-netizen.github.io/Brisbane/` once GitHub Pages is active. Private repository Pages availability depends on the GitHub plan.

## Photo links

The horizontal photo rows link to original source pages or image files. Photos are not copied into this repository.
